먼저 고칠 순서

  1. 카카오 API 키 주입과 iOS 위치 권한 문구

    지금 상태로는 근무지 검색이 항상 실패해서 온보딩 1단계를 마칠 수 없고, iOS에서는 위치 권한 요청이 동작하지 않습니다.

  2. 자정을 넘긴 근무, 출근 쿼리 인덱스

    날짜가 바뀐 뒤에는 퇴근할 수 없고, 복합 인덱스가 없으면 출근 단계에서 예외가 납니다. 매일 쓰는 핵심 흐름입니다.

  3. 온보딩 완료 확인 연쇄

    router가 onboardingCompleted를 확인하지 않습니다. 근무지 단계를 건너뛰면 goals=null이 남고, 마이페이지에서 오류가 납니다.

  4. 회원가입 롤백, 탈퇴 순서

    고아 Auth 계정이 생기거나, 데이터는 지워졌는데 계정은 남는 경우를 막아야 합니다.

  5. 휴가·외근 신청을 Firestore에 저장

    신청이 저장되지 않아서 외근·휴가·결근 상태가 기록되지 않고, 출근할 때 외근 승인 확인도 항상 false입니다.
